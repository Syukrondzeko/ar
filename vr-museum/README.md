# VR Museum

Walk around a virtual **landmark museum**: the Eiffel Tower and the Leaning Tower of Pisa stand on
pedestals with info signs, a robot guide welcomes you, and a fox rests by the Pisa tower.

This is **VR (virtual reality)**: a fully virtual world, with no camera needed. It works on a laptop now and
is ready for a VR headset later.

## Controls (laptop)

| Action | How |
|---|---|
| Look around | **Drag** with the mouse |
| Walk | **W A S D** or the arrow keys |
| Teleport | **Click a blue circle** on the floor; you glide there and turn to face the exhibit |
| Robot dances | **Click the robot** |
| Fox runs | **Click the fox** |

The robot guide always turns to face you, **waves** and says hello when you come within 4 m.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole museum |

Models are shared with other projects: robot and fox from `../hiro-model/models/`, Eiffel and Pisa from
`../image-tracking/models/` (see that README for the CC BY credits). The museum's own files are tiny;
the sky, hills and trees are generated by code.

## Built with

- [A-Frame](https://aframe.io) 1.5.0: 3D/VR scenes in HTML (built on WebXR)
- [aframe-environment-component](https://github.com/supermedium/aframe-environment-component) 1.3.3: sky, hills and trees generated by code (48 KB)
- [aframe-extras](https://github.com/c-frame/aframe-extras) 7.2.0: `animation-mixer` for robot and fox animations

## How to run

```bash
cd ar   # your project folder
python3 -m http.server 8000
```
Open `http://localhost:8000/vr-museum/`.

## How it works

### The player "rig"
```html
<a-entity id="rig" position="0 0 11">                        <!-- moved by teleporting -->
  <a-entity id="camera" camera position="0 1.6 0"            <!-- eyes at 1.6 m -->
    look-controls wasd-controls></a-entity>                  <!-- mouse look + WASD walk -->
</a-entity>
```
Teleporting animates the **rig** to the circle, so the camera (your eyes) comes along.

### Clicking things
`cursor="rayOrigin: mouse"` on the scene turns the mouse into a pointer, and
`raycaster="objects: .clickable"` limits it to things with `class="clickable"`. Those get a normal
`click` event, so custom components just listen for it.

### Custom components (all in `index.html`)

| Component | What it does |
|---|---|
| `fit-model` | Scales a model to a real height in meters. `hide:` removes parts by material name (used to hide the Eiffel model's park ground) |
| `teleport` | Click → glide the rig there and face the exhibit |
| `guide` | Robot faces you every frame (`tick`), waves and shows the bubble when you're within 4 m |
| `click-anim` | Click → play an animation a few times, then back to idle |
| `look-at` | Keeps the speech bubble facing you |

### Shadows
`shadow="type: pcfsoft"` on the scene, `castShadow` on the sun light, `castShadow` on every model mesh
(in `fit-model`), and `shadow="receive: true"` on the floor and pedestals.

## Later: real VR

- **Phone + Cardboard viewer:** open the page on a phone and press the **VR goggles** button (bottom
  right) for side-by-side VR. Moving the phone looks around.
- **VR headset (e.g. Meta Quest):** open the page in the headset's browser and press **Enter VR**.
  Teleport and hand controllers would need a small extra component.

## Ideas to try

- Add another exhibit: copy an exhibit block, change the model and the sign text, and add a teleport circle.
- Change the world with the environment presets: `preset: forest`, `japan`, `egypt`, `starry`, `tron`.
- Add sounds: background music, or a "hello" when the robot waves (`<a-sound>`).
